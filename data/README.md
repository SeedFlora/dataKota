# Public data boundary

No real Jakarta CRM records are distributed in this repository. This directory
contains only `schema.example.csv`, a single synthetic row illustrating the
fields expected by the locked experiment configuration.

The example is not suitable for training, evaluation, statistical inference,
or reconstruction of any reported result. Authorized data must be processed in
a controlled environment and must satisfy the schema, class-map, temporal,
leakage-group, and hash-receipt checks implemented by the repository.
