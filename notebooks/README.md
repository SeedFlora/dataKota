# Historical workflow notebooks

These notebooks document the exploratory preprocessing, split, embedding,
fusion, and error-analysis workflow inspected by the paper's evidence audit.
All stored outputs and execution counts were removed before publication to
avoid redistributing embedded report content or participant-related output.

They require authorized local data and are not the confirmatory evaluation
entry point. Use the locked configuration and command-line tools in `configs/`
and `tools/` for a future controlled evaluation. Notebook file names and hashes
from the original audit snapshot remain recorded in
`docs/audit/audit_corpus_manifest.csv`; the public, output-cleared copies have
different hashes by design.
